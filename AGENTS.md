# AI Agents Development Guidelines

Этот файл содержит основные правила и соглашения для AI-агентов (и людей), работающих над этим проектом. Пожалуйста, строго следуйте им при внесении изменений.

## Архитектура и Структура кода

1.  **Директория `src/`:** Весь исходный код приложения (кроме конфигурационных файлов) должен находиться внутри директории `src/`. Не создавайте новые папки в корне проекта, если они не являются глобальными конфигурациями.
2.  **Структура `src/`:**
    *   `/app` - страницы и layout для Next.js App Router.
    *   `/components` - UI компоненты. Разделяйте логику и представление, если компонент становится слишком сложным.
    *   `/lib` - утилиты, функции-помощники и общие константы.
    *   `/hooks` - пользовательские React хуки.
    *   `/db` - все, что связано с базой данных (схемы Drizzle, подключение, миграции).
    *   `/types` - глобальные TypeScript интерфейсы и типы.

## Качество кода (Важно!)

1.  **Никаких костылей и хаков:** Пишите чистый, понятный и поддерживаемый код. Решайте корневую проблему, а не скрывайте ее.
2.  **Избегайте антипаттернов:**
    *   Не мутируйте состояние напрямую.
    *   Не делайте "проп-дриллинг" (prop drilling), если можно использовать Context или стейт-менеджер.
    *   Разделяйте компоненты по принципу единственной ответственности (Single Responsibility Principle).
3.  **Типизация:** Проект использует TypeScript. Использование `any` строго запрещено, за исключением самых крайних случаев. Определяйте четкие интерфейсы.

## Безопасность и Данные

1.  **Конфиденциальные данные:** НИКОГДА не коммитьте файлы `.env` (кроме `.env.example`), файлы базы данных (например, `sqlite.db`, `*.sqlite`, `*.sqlite3`) или секретные ключи в репозиторий. Проверьте `.gitignore` перед коммитом.

## Стилизация (Планы на будущее)

1.  В данный момент проект использует Tailwind CSS для быстрого прототипирования.
2.  **Важное правило для стилей:** В будущем стилистика будет перенесена на чистый CSS (или CSS-переменные в `globals.css`) для поддержки светлой и темной тем, а также для упрощения изменения дизайна.
3.  При добавлении новых компонентов старайтесь не перегружать их сложными, жестко закодированными цветами из Tailwind (`bg-[#0a0b0e]`). Рассматривайте возможность использования переменных там, где это уместно, чтобы облегчить будущий переход.

## База данных

1.  Используется SQLite в связке с Drizzle ORM.
2.  Любые изменения схемы базы данных должны вноситься в `src/db/schema.ts`.
3.  Для применения изменений используйте Drizzle Kit (`npx drizzle-kit push` или систему миграций, если она будет настроена в будущем).
